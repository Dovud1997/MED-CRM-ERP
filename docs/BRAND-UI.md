# ONA VA BOLA KLINIKASI — Brand UI

## Визуальное направление

Белая, спокойная медицинская система с тёплым семейным характером. Исходный знак матери и ребёнка сохраняется без изменения силуэта и цвета.

## Принципы UX

- Белые поверхности и мягкий серый фон уменьшают визуальную нагрузку.
- Малиновый используется для бренда, активной навигации и основных действий, но не для больших фоновых областей.
- Статусы не кодируются только цветом: всегда используются текст и/или форма.
- Основные действия доступны с клавиатуры и имеют явные подписи.
- Desktop sidebar превращается в компактный mobile header; контент перестраивается без горизонтальной прокрутки.
- Пустые состояния объясняют, почему данных нет, и предлагают следующее действие.
